# אתר האדמו״ר מקאזניץ שליט״א

אתר סטטי (HTML/CSS/JS בלבד, ללא בנייה): רשימת גלריות תמונות ווידאו מאירועי חצר הקודש, לפי אירוע ותאריך הצילום.

- `index.html` — עמוד הבית: פתיח + רשימת הגלריות, מקובצות לפי שנה עברית, עם סינון תמונות/וידאו.
- `gallery.html?g=ID` — עמוד גלריה אחת: תמונות (עם לייטבוקס), סרטונים, ומעבר לגלריה הקודמת/הבאה.
- `data/galleries.js` — **כל התוכן**. כאן מוסיפים אירועים, תמונות וסרטונים.
- `js/site.js` — תאריכים עבריים (מחושבים אוטומטית מתאריך הצילום; צילומי ערב נספרים ליום העברי הבא), כרטיסים, לייטבוקס.

## הרצה מקומית

```bash
cd site
python3 -m http.server 8080
# http://localhost:8080
```

## פריסה

כל התיקייה `site/` היא האתר. מעלים אותה כמו שהיא ל‑Netlify, Vercel, GitHub Pages או כל אחסון סטטי.

## הוספת גלריה (אירוע)

1. שומרים את התמונות ב‑`assets/img/` — גרסה לרשת (כ‑1800px בצד הארוך) ותמונה ממוזערת (כ‑900px).
2. סרטונים: MP4 בקידוד H.264 + AAC ב‑`assets/video/`, עם תמונת פוסטר ב‑`assets/img/`:
   `ffmpeg -i in.mov -c:v libx264 -crf 25 -pix_fmt yuv420p -c:a aac -movflags +faststart out.mp4`
3. מוסיפים רשומה ל‑`window.GALLERIES` ב‑`data/galleries.js`:

```js
{
  id: 'lag-baomer-5786',                 // מזהה באנגלית, ייחודי
  title: 'הדלקה בל״ג בעומר',
  date: '2026-05-05T21:10:00+03:00',    // מועד הצילום; null אם לא ידוע
  // hebrewDate: 'ל״ג בעומר תשפ״ו',     // רשות: עוקף את החישוב האוטומטי
  place: 'חצר הקודש קאזניץ',            // רשות
  items: [
    { type: 'photo', src: 'assets/img/x.jpg', thumb: 'assets/img/x-900.jpg', ratio: '4 / 3', alt: 'תיאור', caption: 'כיתוב' },
    { type: 'video', src: 'assets/video/x.mp4', poster: 'assets/img/x-poster.jpg', caption: 'כיתוב' },
  ],
}
```

הגלריות ממוינות אוטומטית מהחדשה לישנה; גלריות ללא תאריך מופיעות בסוף תחת "ללא תאריך".

## פרטי יצירת קשר

עדיין לא סופקו. יש להוסיף אותם בתוך `.footer-text` ב‑`index.html` (ההערה במקום מסמנת זאת).
